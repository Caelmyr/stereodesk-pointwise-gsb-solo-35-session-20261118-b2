# StereoDesk 双目照片工作台

导入实际拍摄的左眼和右眼照片，校正右眼偏移与微小旋转后检查可用裁图、红青立体照片和可信视差。工作台不改写原图，可重开或用工程 ZIP 交接。

从此目录执行 `docker compose up -d --build`，打开 `http://127.0.0.1:18938/`。Compose 使用独立的 `stereodesk-data` 卷。容器从 Python 3.12 基础镜像按锁定的依赖构建。也可在 Python 3.11 或 3.12 环境安装 `requirements.txt` 后运行 `python -B app.py`。直接启动默认把工程保存到 `./data`，可通过 `STEREODESK_DATA_DIR` 指定目录。

- 「纸艺展台」等三个样例为合成图像。普通拍摄导入须提供应用 EXIF 朝向后尺寸一致的单帧 PNG、JPG、WebP 或 TIFF，每眼至少 96 × 64，最多 240 万像素。立体匹配基于已经大致水平对齐的图像。可用「对齐线」和「叠加」检查调整。
- 「共同裁切图」是两眼均完整支持的同尺寸图像对。裁框采用原画布坐标，右边界和下边界为开区间。红青会聚调整只作用于相应预览和红青 PNG。
- 匹配以左眼为主坐标，正视差表示右眼对应点位于更靠左的列。用「可信区」查看双向一致性、弱纹理以及有效支撑。估计存在遮挡和失配，不是三维真值。点击预览可以检查像素，已填写毫米基线和像素焦距后可读标距估计。来源光学畸变、非水平极线或数字缩放会影响量测。
- 下载的 NPY 使用以像素为单位的单通道浮点矩阵，未知位置为 NaN。CSV 保留所选左眼整行的位置、数值和原因。工程 ZIP 包含两眼来源图与设置，应使用页面上的恢复入口导入。
- 页头「图像准备」进入另一项完整的通用工作区，可进行图像序列配准、校色、合成和导出。它使用单独数据目录。
